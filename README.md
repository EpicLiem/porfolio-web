# Portfolio v2

A minimal Next.js 16.4.3 App Router starter for a new portfolio. This is a blank foundation, not the finished design. The previous site's pages, content, assets, integrations, and dependencies have been removed from this branch.

## Development

Use Node.js 22.13 or newer and npm.

```sh
npm ci
npm run dev
```

## Verification

```sh
npm run lint
npm run typecheck
npm run build
```

Run the production build locally with `npm run start`.

Draft pages are marked `noindex, nofollow`. Update the metadata before publishing the finished portfolio.
