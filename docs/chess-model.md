# Liemfish browser integration

The portfolio owns the chess interface. [Liemfish](https://github.com/EpicLiem/liemfish), in `packages/browser`, owns the browser inference engine, selected model contracts, feature encoding, legal move sampling, timing prediction, worker lifecycle, trained time-control metadata, asset preparation, and engine tests.

The engine is consumed through the exact npm version `@epicliem/liemfish-browser@0.2.0`. Do not copy its source back into this repository or add a dependency on a local checkout. `lib/chess/model.ts` is a small client adapter choosing `/chess/engine/` as the same-origin asset base; `lib/chess/time-controls.ts` reexports the package's trained controls.

The board, desktop window, clocks and move scheduler, game state/history, promotions, premoves, sounds, accessibility, and all styling remain here. These remain responsible for terminal positions, charging elapsed time/increments, and rejecting stale predictions after reset or timeout.

## Setup

Clean builds need no local Liemfish checkout. `prebuild` and `predev` run `ensure:chess`, which downloads the six model export/license files pinned in `scripts/chess-assets-source.json`. The URLs use immutable commit `820fa9dfb6f87ca371373bac15394fb022134daa`; ONNX files use GitHub’s LFS media endpoint. Every download must match its recorded size and SHA-256 before it is written.

```sh
npm ci
npm run dev
```

The preparation script calls the installed package’s `prepareAssets` function, which copies its prebuilt worker, pinned ONNX Runtime WASM files, notices, and the selected model pair into `public/chess/engine/`. It verifies the model exports and writes an asset manifest. This generated directory is ignored by Git. `public/chess/pieces/` contains GUI artwork and stays in this repo.

```sh
npm run verify:chess
npm run build
npm run start -- --port 3109
```

Verification checks every asset's size and SHA-256, the selected export contracts, and packaged worker/runtime bytes. It does not need the Liemfish checkout. Both `predev` and `prebuild` prepare missing assets and verify existing ones, so outdated artifacts fail before serving a broken chess game. Update the source pin and prepare assets again after upgrading the npm package. CI automatically prepares missing assets before Next.js builds. Downloads and package verification run in a temporary sibling directory; the complete output is renamed into place only after verification. A failed download leaves no partial output, and invalid existing assets fail instead of being silently replaced. To prepare from a local Liemfish checkout explicitly, use `npm run prepare:chess -- --source /path/to/liemfish`.

## Consumer contract

```ts
import { createModel } from '@epicliem/liemfish-browser';
const engine = createModel({ assetBaseUrl: '/chess/engine/' });
await engine.loadModel(onProgress);
const reply = await engine.predict(position, { signal });
engine.disposeModel();
```

Loading is lazy and begins only after the visitor starts a game. The package has no React dependency or import-time browser globals. It creates an isolated module worker per engine instance. All inference and model downloads use same-origin files; no inference service or CDN is involved.

`ModelPosition` contains the current FEN, last eight actual consecutive-ply FENs ending at that position, starting time and increment, both remaining clocks, both completed move-duration histories, previous capture flag, and rating context. The GUI still passes 491/529, but `lib/chess/model.ts` replaces them with the package's `ratingContextForControl(initialSeconds, incrementSeconds)` (230 bullet, 220 blitz, 680 rapid or longer). These are historical context, not a measured playing strength. The returned `{ uci, targetSeconds }` uses the total target turn duration, including inference latency. The GUI waits only the remainder, checks its request generation and legal game state, then commits and applies increment.

Since 0.2.0 the selected pair is the recent-game epoch-6 move model `bc97f3882bf51be3599eca78f178a9066bfc0c19d196321c3bd8c2bc779a168a` (adapted on 2024–2025 games, selected on 2026 games) and the unchanged E05 epoch-5 timing head `85b5dc3ab33dfde62ca511ea0c5a4f9e8ca1ece0846fa2bc2a1aaadca56a1921`, totaling 91,757,750 bytes. Selection, verification, and model/runtime license notices are maintained by Liemfish and its package. Raw training data is not needed by the portfolio or shipped in the npm package.

## Ownership and verification

- Engine changes and their encoding/timing/worker tests: Liemfish `packages/browser`.
- GUI/game rules, clocks, premoves, sounds, adapter contract test: this repo's `app/desktop/chess` and `lib/chess`.
- Engine assets: generated by the installed package, never maintained manually here.

Run `npm run test:chess`, `npm run test:forms`, `npm run lint`, `npm run typecheck`, and `npm run build` here. Engine unit tests run in Liemfish. Browser acceptance must still exercise the installed package with real model files: lazy load, progress, legal sampled moves and timing, failure/retry, reset cancellation, minimize/restore, and no page errors.
